# eDarris Office, Education & Business Supplies

A bilingual (English/Arabic) marketing site built with Next.js and Tailwind CSS. Content is editable via Netlify CMS and inquiries are captured through Netlify Forms.

## Development

Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

## Deploy to Netlify

Click the button below to deploy your own copy to Netlify.

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/your/repo)

Netlify CMS is available at `/admin` once deployed.
